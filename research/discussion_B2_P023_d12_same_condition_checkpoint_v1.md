# Can 287 qubits buy the same memory lifetime as 449?

Distance 12 saves 162 active sites versus distance 15 while keeping a local circuit, seven ticks per round and the same 30-round decoding look-ahead. The smaller patch has 0/1,024 failures in each short X/Z cohort with or without paired readout flips. The meaningful test is one million uninterrupted rounds. The candidate is now running it, and the distance-15 reference is still accumulating its independent long cohorts.

**If both patches passed, would you trust the 36.1% qubit-round saving—or is there another cost that should be held equal before it counts?** If you have a smaller patch or a stronger correlated noise model, can you specify its local schedule and what would falsify it without loosening the two-basis failure target?
