# What would prove a leakage flag helped on the very same shot?

The new Willow release let us rebuild 400,000 distance-6 X/Z hardware records bit for bit. Locally, with the same supplied prior, correlated matching had fewer logical errors in both bases, but this is purely binary syndrome decoding. Separate Sycamore IQ data have four prepared classes and measurable false/missed flags; they belong to a different acquisition and cannot label the Willow shots.

**What is the smallest public export that would demonstrate a real leakage-aware gain rather than a decoder or calibration mismatch?** Would a shot/qubit/readout join with an acquisition-matched confusion matrix and a frozen holdout suffice, or should the study also include a negative control that deliberately shifts the flags by one round?
